# E1 Amendment-001：审卷自动化与 t2/t3 重封卷

> 2026-09-13 · 对预注册件 `2026-09-13-e1-protocol-preregistration.md` 的**追加**（原件封存不动）
> 决策依据：`docs/references/exam-review-automation-survey.md`（L4）+ 两卷自动审证据包 + 用户三项拍板（J1 回滚 / J2a 裁剪 / J3 本 amendment）

## 一、协议条款修订

1. **§4 隐藏卷定义**：由"该票修复新增的全部测试文件"改为"**票头 `test_files:` 声明 ∩ 修复区间实际变更**，其中经自动审判定不可推导的断言/文件可剔除（须溯源记账）"。
2. **新增常设关卡（造卷第三关与封卷之间）**：每张新卷跑 `scripts/e1/review_exam.py` 四段自动审（S1 静态重合 / S2 N=3 flake / S3 MPE 宽松率 / S4 仓可见 judge），`derivation-review` 人闸改为**裁决证据包**（flagged 复核+签字），不再裸读题面。
3. **票面时点规则**：题面一律取**考卷基线时点的历史票版**（`--ticket-at`），实现期附注（HITL 记录，含答案）不得进入题面。

## 三、造卷器缺陷修复（顺带产出，入平台）

- **夹带洞**：修复区间跨越邻居票整备提交时，别人票的测试会进隐藏卷——现默认按票头声明过滤（DEFECT-015 同族票面粒度问题在造卷侧的堵法）。
- **连带打破洞**：被剔测试若在基线已存在且被本票实现打破（原修复被迫 align 它的场景），判分命令自动 `--ignore`，避免收集期崩溃误拒题。

## 四、测量口径影响声明（诚实记账）

- t2v2 的 P2 判分粒度变粗：打包算法内部性质测试（BFD 配对/证书精确性）不再独立兜底，核心行为（守恒/预算/阈值/三态）仍在 API 契约层断言内。三臂同定义判分，**臂间比较效度不受影响**；绝对通过率含义变窄，报告注明。
- t3r 剔的三个降级/间隙语义测试所对应的行为（模式上限回退、劣化降级）不在判分面；票内 AC2"三态判定"仍由保留测试覆盖。
- S3 变异两卷宽松率均 0/4（原隐藏卷对四算子变体全杀伤）——裁剪未损伤隐藏卷强度，此为裁前实测。

## 五、票池影响

report 集候选：t2v2 + t3r（待复审包 auto-pass 后转 derivation-review 签字闸）。主段仍按协议 ≥7 票——新票造卷一律走"三道关+四段审"全链，出包即审。
